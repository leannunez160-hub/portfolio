# Student Portfolio Website

A responsive student portfolio made with plain HTML, CSS, and JavaScript. It is designed to be hosted for free with GitHub Pages.

## Files

- `index.html` — website content and sections
- `style.css` — layout, colors, responsive design
- `script.js` — mobile navigation behavior

## Before publishing

1. Open `index.html` and replace `Leandro Duat` if needed.
2. Replace `YOUR-EMAIL@example.com` with your professional email address.
3. Review the About, Skills, and Projects sections. Keep only details that accurately describe your experience.
4. Add your own project screenshots and working links when available.
5. Open `index.html` in a browser and test the navigation and mobile layout.

## Publish with GitHub Pages

1. Create a **public** repository named `portfolio` on GitHub.
2. Upload the contents of this folder to the repository root (not the ZIP file).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then click **Save**.
6. Wait for deployment and open the published URL shown on the Pages settings screen.

The URL usually looks like `https://YOUR-USERNAME.github.io/portfolio/`.

## Note

This site uses no build tools or dependencies. The external Google Fonts import is optional; the site will fall back to system fonts if unavailable.
